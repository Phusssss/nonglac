## 🚀 HƯỚNG DẪN TRIỂN KHAI

### Bước 1: Cập nhật DNS
```
A Record: @ -> IP server
CNAME: www -> nonglac.com
```

### Bước 2: SSL Certificate
- Cài đặt SSL cho https://nonglac.com
- Redirect HTTP -> HTTPS

### Bước 3: Google Search Console
1. Thêm property: https://nonglac.com
2. Verify ownership
3. Submit sitemap: https://nonglac.com/sitemap.xml
4. Submit news sitemap: https://nonglac.com/sitemap-news.xml
5. Submit products sitemap: https://nonglac.com/sitemap-products.xml

### Bước 4: Google Analytics
- Cập nhật tracking ID trong index.html
- Thiết lập goals và events

### Bước 5: Social Media

- Tạo YouTube: youtube.com/@nonglac

## 📊 KPIs CẦN THEO DÕI

### Search Console Metrics
- Impressions (lượt hiển thị)
- Clicks (lượt click)
- CTR (tỷ lệ click)
- Average position (vị trí trung bình)

### Target Keywords
1. **Primary:** nông nghiệp việt nam, mạng xã hội nông nghiệp
2. **Secondary:** giá nông sản, giá cà phê, giá lúa gạo
3. **Long-tail:** cộng đồng nông dân việt nam, diễn đàn nông nghiệp

### Page Speed Targets
- First Contentful Paint: < 1.5s
- Largest Contentful Paint: < 2.5s
- Cumulative Layout Shift: < 0.1
- First Input Delay: < 100ms
